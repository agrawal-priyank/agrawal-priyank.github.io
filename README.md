# Priyank Agrawal

Personal site, served at [agrawal-priyank.github.io](https://agrawal-priyank.github.io/).

Static HTML, CSS, and a little JavaScript. GitHub Pages publishes from `master`.

## Local preview

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Layout studies

Four placeholder templates live under [`templates/`](templates/index.html):

- [Paper](templates/paper.html) — light, print-like
- [Prompt](templates/prompt.html) — terminal
- [Vitrine](templates/vitrine.html) — split-screen
- [Folio](templates/folio.html) — dark editorial

Pick one, then drop in real copy. GitHub Pages still publishes from `master`; these pages are only on the review branch until merge.
